# Exercícios Vazios

Aplicação Front-End desenvolvida com HTML e JavaScript para prática de exercícios de programação e lógica, permitindo completar desafios e implementar soluções diretamente no navegador.

---

## 📋 Sobre o Projeto

O projeto foi criado com o objetivo de auxiliar no aprendizado de programação através de exercícios vazios, onde o usuário deve completar a lógica proposta utilizando JavaScript.

A aplicação oferece uma estrutura simples para prática de conceitos fundamentais de desenvolvimento web e lógica de programação.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- JavaScript (Vanilla JS)

---

## 🎯 Funcionalidades

- Exercícios interativos
- Estrutura de desafios vazios para completar
- Manipulação de DOM
- Execução de lógica em JavaScript
- Interface simples e prática para estudos

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/exercicios-vazios.git
```

2. Acesse a pasta do projeto:

```bash
cd exercicios-vazios
```

3. Abra o arquivo `index.html` no navegador.
